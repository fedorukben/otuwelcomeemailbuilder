How to Send It

Suggested subject: Welcome to Ontario Tech University

Works in classic Outlook, new Outlook and Outlook on the web.

  1. Fill in the form and check the preview.
  2. Click Copy email for Outlook.
  3. In Outlook, start a New Email, click in the message body and press Ctrl+V (⌘+V on a Mac).
  4. If the text turns black or the font changes, undo, change the paste setting described in the box below, and paste again.
  5. If Outlook added your usual signature, delete it. The email already has one.
  6. Add the recipient and subject, and attach the New Employee Orientation Checklist.
  7. Send a test to yourself first (see the checklist below), then send it to the new employee.
Do this once so the design survives pasting. Outlook's default paste strips fonts and text colours.
New Outlook or Outlook on the web: Settings (gear) → Mail → Compose and reply. Make sure Compose messages in is HTML, then under Cut, copy, and paste set Pasting from other apps to Keep source formatting. Save, then paste the email again.
Classic Outlook: File → Options → Mail → Editor Options → Advanced, then under Cut, copy, and paste set Pasting from other programs to Keep Source Formatting.

Classic Outlook for Windows only. New Outlook and Outlook on the web don't have this option, so use Copy and paste there.

  1. Click Download HTML and save the file.
  2. In classic Outlook, start a New Email and click in the message body.
  3. Go to Insert → Attach File → Browse This PC and select the file you saved.
  4. Click the small arrow on the Insert button and choose Insert as Text.
  5. Add the recipient, subject and checklist attachment, send yourself a test, then send.
Don't see Insert as Text? Add the Attach File… command to your Quick Access Toolbar: File → Options → Quick Access Toolbar, choose All Commands, pick Attach File…, click Add. Using that button shows the Insert as Text option.

Before You Send

  • Your message format is HTML. In the message window: Format Text → HTML. Plain Text removes all formatting.
  • The test email looks right on your computer and on your phone.
  • The header photo appears. If it doesn't, use the Advanced header photo option above.
  • The checklist file is attached.
